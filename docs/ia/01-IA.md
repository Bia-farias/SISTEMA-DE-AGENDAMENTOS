# IA — 01 — Visão Geral da Inteligência Artificial

---

## 1. Filosofia

A IA no NGB Agenda IA não é um chatbot decorativo. Ela é a **assistente da empresa**: entende os dados reais do negócio e fornece respostas úteis, ações concretas e análises personalizadas.

---

## 2. O que a IA pode fazer

| Categoria | Capacidade | Exemplo |
|-----------|-----------|---------|
| **Consulta** | Responder perguntas sobre os dados | "Quantos agendamentos tenho hoje?" |
| **Análise** | Analisar performance e tendências | "Qual foi meu faturamento essa semana?" |
| **CRM** | Identificar clientes e padrões | "Quais clientes estão inativos?" |
| **Criação** | Criar agendamentos por voz natural | "Agende João amanhã às 15h para corte" |
| **Comunicação** | Gerar mensagens de WhatsApp | "Crie mensagem de lembrete para Ana" |
| **Resumo** | Resumir a agenda ou semana | "Resuma minha semana" |

---

## 3. Arquitetura da IA

```
Usuário digita pergunta
         │
         ▼
React → POST /api/ai
  (com token JWT do usuário + mensagem)
         │
         ▼
Vercel Function:
  1. Valida token JWT
  2. Identifica tenant_id
  3. Analisa intenção da mensagem
  4. Consulta dados relevantes no Supabase
  5. Monta contexto rico com os dados
  6. Envia para Groq API
         │
         ▼
Groq (LLM) processa com contexto real
         │
         ▼
Resposta retorna para o React
         │
         ▼
Exibida no chat + salva no banco
```

## 5. Histórico de Conversas

- Cada sessão de chat é salva como uma `ai_conversation`
- As mensagens são salvas em `ai_messages`
- O usuário pode retomar conversas anteriores
- O histórico recente é incluído no contexto enviado para a IA

## 6. Limites e Custos (Groq)

| Modelo | Tokens/min | Tokens/dia | Custo |
|--------|-----------|-----------|-------|
| llama-3.3-70b-versatile | 6.000 | 500.000 | Gratuito (plano free) |
| mixtral-8x7b-32768 | 5.000 | Ilimitado | Gratuito (plano free) |

> O plano gratuito da Groq é mais que suficiente para um MVP. Em produção com muitos usuários, avaliar planos pagos.
